# Flow EVM Solidity Smart Contract

This project contains a simple Solidity smart contract deployed to the **Flow EVM Testnet** as part of the HackQuest x Flow Build Station.

## 🚀 Project Overview

This smart contract demonstrates basic Solidity functionality and deployment to Flow's Ethereum Virtual Machine (EVM) compatible environment. It was written and deployed using **Remix IDE** and tested on the **Flow EVM Testnet**.

## 🔗 Deployed on Flow EVM Testnet

- **Contract Address:** `0xd9145CCE52D386f254917e481eB44e9943F39138`

## 🛠️ Tech Stack Used

- **Solidity**
- **Remix IDE**
- **MetaMask** (configured for Flow EVM)
- **Flow EVM Testnet**
- **GitHub**
